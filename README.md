# Content Creation 101

A free knowledge base about growing online with content: personal brand, hooks, storytelling, psychology, going viral, video, articles, distribution, systems, making money and writing

It is made to be given to AI. Load it into ChatGPT, Claude or NotebookLM, and the AI becomes a content coach that knows all 176 lessons and can use them on your own posts

Everything in it comes from 65 videos and articles by creators who grew huge audiences, sorted into 11 modules. Every creator is credited in [CREDITS.md](CREDITS.md). Put together by [@BuzzMalx](https://x.com/BuzzMalx)

## What's inside

- [Module 1: Personal brand and positioning](guide/01-personal-brand-and-positioning.md): Decide what you want to be known for, prove it, repeat it, and give it time
- [Module 2: Hooks](guide/02-hooks.md): Write openings that stop the scroll, make your topic clear in a second, and make the right people want the next line
- [Module 3: Storytelling](guide/03-storytelling.md): Storytelling is a skill you can learn: give people a reason to care, a question to guess and a surprise
- [Module 4: Psychology and attention](guide/04-psychology-and-attention.md): People scroll without thinking, so learn what makes them stop, what makes them care and what makes them act
- [Module 5: Ideas, packaging and virality](guide/05-ideas-packaging-and-virality.md): Pick ideas people already want, package them so people click, and make more of what wins
- [Module 6: Formats and video](guide/06-formats-and-video.md): Pick a few formats you can keep making, build the hook around what people see first, keep production simple, and post at a pace you can keep
- [Module 7: Articles and long-form writing](guide/07-articles-and-long-form-writing.md): Long pieces build trust. Pick a fresh topic, open with proof and a clear promise, make the article easy to scan, then push it after you publish
- [Module 8: Distribution and growth](guide/08-distribution-and-growth.md): Get people to see your work, then turn their attention into trust, an audience you own, and sales
- [Module 9: Systems, teams and AI](guide/09-systems-teams-and-ai.md): Build a system and a team so your content keeps going without you doing everything
- [Module 10: Money and careers in content](guide/10-money-and-careers-in-content.md): Attention turns into money when people trust you, you have something to sell, and buying is easy
- [Module 11: Writing and copywriting](guide/11-writing-and-copywriting.md): Write clear, specific, human words that get the right reader to take the right action
- [The Personal Brand Playbook](PLAYBOOK.md): every step from the guide in order, with questions to answer for your own brand
- [Credits](CREDITS.md): every creator, with a link to every original video and article
- [llms.txt](llms.txt): a short index for AI tools that read websites and repos

Every lesson uses the same labels, so the AI can find each part: Big idea, How it works, Steps, Examples, Mistakes, Try it

## How to give it to AI

First download the files: on this page click the green Code button, then Download ZIP, and unzip it

### ChatGPT

1. Open ChatGPT and create a new Project (in the left sidebar)
2. Add all the module files, PLAYBOOK.md and CREDITS.md to the project files
3. Start a chat inside the project and use one of the prompts below

For one quick question you can also attach a single module file to a normal chat

### Claude

1. Open claude.ai and create a new Project
2. Add all the files to the project knowledge (or add this repo straight from GitHub if you have the GitHub integration)
3. Start a chat inside the project and use one of the prompts below

### NotebookLM

1. Open notebooklm.google.com and create a new notebook
2. Add the files as sources
3. Ask your questions in the chat. NotebookLM shows which part of the guide each answer comes from

### Other AI tools

Tools that can read a website or a GitHub repo (for example ChatGPT with browsing, Cursor or Claude Code) can start from [llms.txt](llms.txt). It lists every file with a direct link

## Prompts to copy

Paste one of these after the guide is loaded. Swap the parts in [brackets] for your own

**1. Fix my posts**

```
You're my content coach. Use only the Content Creation 101 guide I gave you.
Here are my last 10 posts with their views: [paste your posts]
Tell me the 3 biggest things I should fix, explain each one simply, and name the lesson it comes from.
Then rewrite my weakest post using what the guide teaches.
```

**2. Write hooks**

```
Use the hook lessons in the Content Creation 101 guide (module 2).
Write 10 hooks for a post about [your topic] for [who it's for].
For each hook, say which idea from the guide it uses and why it should stop the scroll.
```

**3. Build my brand and a 30-day plan**

```
Use the Personal Brand Playbook from the Content Creation 101 guide.
Ask me the questions from Part A one at a time and wait for my answer each time.
When we're done, write my positioning in 3 sentences and a 30-day content plan
(what to post each day, which format, and which lesson each idea comes from).
```

**4. Teach me a module**

```
Teach me module [number] of the Content Creation 101 guide like a coach.
Explain one lesson at a time in simple words, then give me the "Try it" task.
Check my answer and give feedback before you move to the next lesson.
```

Tip: ask the AI to name the lesson behind every piece of advice. That way you can check it and read more
